##  Proyectos destacados

### 🔐 [login-php-mysql](https://github.com/sergiocl21/login-php-mysql)
Sistema completo de autenticación de usuarios con PHP y MySQL.
- Registro e inicio de sesión con validación
- Encriptación de contraseñas con `password_hash`
- Manejo de sesiones con `$_SESSION`
- Dashboard privado y cierre de sesión
- Protección de rutas (middleware básico)

`PHP` `MySQL` `Bootstrap` `Sesiones` `Seguridad`

---

### 🗄️ [php-mysql-crud](https://github.com/sergiocl21/php-mysql-crud)
Aplicación web con operaciones CRUD completas sobre una base de datos MySQL.
- Crear, leer, editar y eliminar registros
- Conexión a base de datos con PHP
- Interfaz limpia con Bootstrap

`PHP` `MySQL` `Bootstrap` `CRUD` `Backend`

---

### 🐍 [python-excel-automation](https://github.com/sergiocl21/python-excel-automation)
Script de automatización para procesamiento y análisis de archivos Excel de ventas.
- Lectura de Excel con `pandas`
- Validación de estructura de datos
- Cálculo de totales y estadísticas
- Generación de resumen por cliente y top 3

`Python` `pandas` `Excel` `Automatización` `Reportes`
